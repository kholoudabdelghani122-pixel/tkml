# TKML Variant 01: Horizon

Centred hero with an orange horizon, service bento, horizontal process, and operating-principle cards.

## Files

- `index.html`: page markup and real TKML copy.
- `style.css`: complete responsive styling, gradients and code-drawn visuals.
- `script.js`: page interactions and enquiry-brief preparation.
- `AGENTS.md`: project context and design rules for Codex.

## Preview locally

No installation, build step, API keys, or framework required. Open `index.html` directly for a visual preview, or serve this folder for the best browser behaviour:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`. Stop with Ctrl+C. Clipboard actions work best on localhost or HTTPS.

## Use in Codex

Extract this ZIP and open the extracted project folder in Codex. Use this starting request:

> This is the existing TKML landing page, Variant 01. Read AGENTS.md and the HTML, CSS and JavaScript. Run a local preview and continue from this exact design. Preserve the current layout, copy, gradients and responsive behaviour unless I request a specific change.

## Brand system

- Primary brand ink: `#0D1C22`
- Orange accent: `#F05B1B`
- Pale blue support: `#BBF1FF`
- Near-black page canvas, off-white headings, muted grey body text.
- Brand font: Neue Regrade, bundled in `assets/fonts/`.

## Current behaviour and limits

The page is static HTML/CSS/JavaScript. Forms prepare a brief locally for copying or downloading; they do not send enquiries, email, or store submissions. I Supply is explicitly a planned product. The 70+ years claim refers to combined team experience.

All graphics are CSS or inline SVG; no image downloads are needed. Platform-specific deployment metadata and authentication details are excluded.
